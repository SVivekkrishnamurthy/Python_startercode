git pull origin <branch-name> -> pull from certain branch
git checkout -b <branch-name> -> to switch to other local branch
git branch -> to check current branch name
git add . -> keep track of file to be committed
git commit -m "" -> to add message to current commit
git push origin <branch-name> -> push branch to branch
git clone --single-branch --branch <branch-name> "<url>" -> to clone particular branch
git init . -> initialise local repo
git remote set-url "<url>" -> set url for local repo
